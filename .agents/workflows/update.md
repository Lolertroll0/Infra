# Update Agent Documentation

Please review the current state of the repository, including recent changes to Terraform files (`*.tf`), configuration templates, and any other project files.

Based on your review, update `.agents/handoff.md` and any other relevant agent-facing markdown files in the `.agents/` directory to accurately reflect the latest status of the project.

Make sure to include:
- A summary of the work completed during this coding session.
- Any new architectural decisions made or design patterns implemented.
- The current deployment status of the infrastructure.
- An updated list of pending TODOs and technical debt that need to be addressed in future sessions.
